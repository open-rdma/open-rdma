面向 AI 时代重新思考 RDMA，让系统的每一层都可以被理解、修改与协同优化。 Rethinking RDMA for the AI era, so every layer can be understood, modified, and co-optimized.

01OPEN

从 Bluespec RTL 到 Linux 用户态与内核态驱动，每一层都公开可审阅，不再依赖闭源 RNIC 黑盒。From Bluespec RTL to Linux user-space and kernel drivers, every layer is open for inspection—no black-box RNIC required.

03 / GPU-FRIENDLY

更短的提交路径，
更自由的系统设计A shorter control path.
More freedom to optimize.

传统 GDR 由 CPU 构建请求；IBGDA 将请求构建移到 GPU。OpenRDMA 让 GPU 只发送极简指令，将完整请求构建交给可编程 NIC。GDR builds requests on the CPU; IBGDA moves that work to the GPU. OpenRDMA keeps the GPU instruction minimal and lets the programmable NIC build the request.

  • 减少 GPU 控制面工作Reduce GPU control-plane work
  • 在 NIC 内集中实现协议策略Centralize protocol policy in the NIC
  • 为软硬件协同优化保留空间Preserve room for hardware-software co-design
