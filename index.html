01 / GPU-FRIENDLY

让 GPU 专注计算，
让 NIC 构建请求。Let the GPU compute.
Let the NIC build.

GDR 依赖 CPU 构建请求，IBGDA 将工作交给 GPU。OpenRDMA 则让 GPU 只发送一条 8-byte Doorbell，由 NIC 完成后续解析与请求构建。GDR builds on the CPU; IBGDA moves the work to the GPU. OpenRDMA lets the GPU submit an 8-byte Doorbell while the NIC builds the request.

01 / PROTOCOL & DATA PATH

ns-3 离线实验ns-3 Offline Lab

从独立 ns-3 网络实验开始，再探索 TX RTL → ns-3 → RX RTL 的离线流水线。Begin with a standalone ns-3 experiment, then explore the offline TX RTL → ns-3 → RX RTL pipeline.

Linux 前置条件LINUX PREREQUISITESgit · make · g++ · Python 3 · CMake ≥ 3.25Makefile 从 ~/.local/bin/cmake 查找 CMake；若未安装，可运行The Makefile looks for ~/.local/bin/cmake; if missing, run python3 -m pip install --user cmake==3.31.10
TERMINAL / LINUX HOST
$ git clone --branch dev https://github.com/open-rdma/open-rdma-driver.git
$ cd open-rdma-driver/ns3/OpenRDMA-Offline
$ make -C Ns3-lab build
$ make -C Ns3-lab lab1
TX RTL → ns-3 → RX RTL

完整离线流水线还需 bsc、Verilator 和 cocotb 2。The full offline pipeline also needs bsc, Verilator, and cocotb 2.

TERMINAL / OFFLINE LAB
$ make COCOTB_PYTHON=/path/to/cocotb2/bin/python3
离线实验自包含，不验证整个 M0–M11 模块树。持续开发中的模块见This self-contained lab does not test every M0–M11 module. See the actively developed OpenRDMA-flow module tree。
